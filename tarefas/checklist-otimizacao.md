# Checklist — otimização pós-teste

- [ ] Pausar todos os conjuntos que não venderam
- [ ] Nos que venderam: +20% de verba a cada 24h, enquanto continuar vendendo
- [ ] Conjunto que vendeu mas não bateu ROAS 1: voltar 2 casas na escada de verba
- [ ] Teste CBO: pausar o criativo que gastou 1 ticket desde o início do teste sem vender (venda real decide)
- [ ] Após editar verba: reativar o conjunto (a edição pausa automaticamente) e conferir que voltou a rodar com a verba nova
- [ ] Conferir os 3 níveis ativos: campanha + conjuntos + anúncios
- [ ] Criativo vencedor (vendeu): preparar para pré-escala — manter o nome original e empilhar o histórico (🏆 + objetivo + modelo + público + data)
- [ ] Nada é pausado, editado ou criado sem aprovação — exceto a regra de pausa do CBO acima
