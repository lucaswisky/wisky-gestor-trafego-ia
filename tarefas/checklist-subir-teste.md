# Checklist — subir um teste de criativo

Use antes de criar qualquer coisa na conta. Não pule passo.

## Dados (pergunte se faltar qualquer um)

- [ ] Ticket do produto (R$)
- [ ] Quantidade de criativos e tipo (VD / IMG / CAR)
- [ ] Público (ABERTO ou interesse específico)
- [ ] Headline completa + subheadline da página
- [ ] URL da página de vendas
- [ ] Pixel / conjunto de dados da conta
- [ ] Data de subida (DD/MM/AA)
- [ ] Número do teste (novo, nunca repetido)

## Montagem

- [ ] Formato escolhido: ABO clássica (4 ou 8 conjuntos, número par) ou CBO Test (1 conjunto, 4–6 criativos)
- [ ] Verba calculada pelo ticket (até R$50 = 1 ticket; acima de R$70 = meio ticket; R$51–R$70 = não vende nessa faixa)
- [ ] Nomes de campanha, conjuntos e anúncios no padrão exato, com emoji, sufixo entre colchetes e data
- [ ] 1 anúncio por conjunto
- [ ] Conversão: Site / Maximizar conversões / pixel da conta / Comprar / Padrão / sem meta de custo
- [ ] Posicionamentos: Advantage+, removendo Audience Network e WhatsApp (exclusão 100%, sem gasto limitado)
- [ ] Destino: Site, destinos personalizados tudo desativado
- [ ] CTA: "Ver detalhes"
- [ ] Configuração do criativo: 0/3 desmarcado
- [ ] Rastreamento: site on, app off, offline on
- [ ] Experiências interativas: off
- [ ] Aprimoramentos essenciais: só 3 de 4 (Mostrar destaques off)
- [ ] Advantage+: tudo off, nenhum criativo gerado por IA
- [ ] UTMs dinâmicas em todos os anúncios
- [ ] Copy: título ≤ 8 palavras, texto principal = headline + subheadline, descrição `⭐️⭐️⭐️⭐️⭐️ (4.9/5.0) Avaliações`

## Antes de publicar

- [ ] Plano exato apresentado e aprovado ("pode criar")
- [ ] Depois de publicar: conferir campanha + conjuntos + anúncios ativos, não só a campanha
